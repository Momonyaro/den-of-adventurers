# Den of Hungry Adventurers
This game was an experiment to both learn more event-based programming within the context of games and also to deepen my knowledge of Godot as an engine.
I would say that it worked out quite well and I'm very pleased by the result (even though the game isn't very long.)

- The game uses engine version: __4.1__
- Platforms that work (for now): __Windows__, __Mac__

Explore and interact with it at your leisure, I will consider forks on a case-by-case basis.
